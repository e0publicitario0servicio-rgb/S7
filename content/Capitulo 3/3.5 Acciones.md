Las acciones organizan lo que puede hacer un personaje durante una situación en la que importa el orden de los acontecimientos. La ficha indica cuántas acciones tiene disponibles, y cada acción, técnica o poder establece qué necesita para utilizarse.

Realizar una acción no siempre requiere una tirada. El Master solicita una cuando corresponde resolver un resultado incierto, siguiendo las reglas de [[3.1 Tiradas]].

## Acciones activas y pasivas

- **[[Palabras Clave#^accion-activa|Acción activa]]:** Se utiliza para ejecutar acciones que requieren este tipo de coste.
- **[[Palabras Clave#^accion-pasiva|Acción pasiva]]:** Se utiliza para ejecutar acciones que requieren este tipo de coste y puede emplearse mientras se realizan acciones activas.

	Los contadores de acciones activas y pasivas determinan cuántas acciones de cada tipo puede realizar el personaje durante una ronda. Cada vez que actúa, contabiliza una acción realizada del tipo correspondiente. Al alcanzar el valor de ese contador, habrá completado todas las acciones de ese tipo permitidas para esa ronda, salvo que una regla le permita realizar acciones adicionales.

Si una descripción no especifica el tipo de [[Palabras Clave#^accion|Acción]], se considera **Acción(Activa)**.

## Acciones por ronda

Al **inicio de cada ronda**, el recuento de acciones realizadas vuelve a 0. Cada personaje puede realizar nuevamente tantas acciones activas y pasivas como indiquen sus respectivos contadores.

## Acciones libres

Una acción con [[Palabras Clave#^libre|Libre]] puede realizarse **durante el turno del personaje o mientras reacciona ante algo**, sin contar entre sus acciones activas o pasivas.

Debe cumplir los demás costes, requisitos y límites que indique su descripción.

## Reacciones

Una [[Palabras Clave#^reaccion|Reacción]] delimita el momento en que puede utilizarse una habilidad, poder u otro efecto: cuando ocurre el desencadenante indicado en su descripción.

Reaccionar no cuenta como una acción activa ni pasiva. No existe un límite general de reacciones por ronda; el personaje puede reaccionar tantas veces como se presenten oportunidades válidas, siempre que disponga de una habilidad, poder o regla que lo permita y cumpla sus costes, requisitos y límites particulares.

Las reacciones se resuelven cuando corresponde a su desencadenante, sin esperar a una fase separada. Mientras reacciona, el personaje también puede realizar [[Palabras Clave#^libre|acciones libres]].

## Acciones intrusivas

Una acción con [[Palabras Clave#^intrusiva|Intrusiva]] puede realizarse fuera del turno del personaje, **antes de que otro personaje declare su siguiente acción**.

Esta palabra clave permite intervenir en ese momento. Los demás requisitos, costes y límites de la acción siguen aplicándose.

## Movimiento

El contador de [[Movimiento]] indica la distancia que utiliza el personaje como referencia para desplazarse. Para hacerlo, elige una de estas acciones:

|Acción|Tipo de acción|Distancia|
|---|---|---|
|**Pasos**|Pasiva|Movimiento.|
|**Andar**|Activa|Movimiento.|
|**Correr**|Todas|Movimiento ×3.|

Cada una de estas opciones puede realizarse **una vez por ronda**, según [[Palabras Clave#^cada|Cada(Ronda)]].

**Correr** requiere dedicar todas las acciones y solo puede declararse si el personaje todavía no ha realizado ninguna acción activa ni pasiva durante ese turno.

El valor del contador de Movimiento permanece igual al desplazarse. Lo que se contabiliza es qué acción ha realizado el personaje y la distancia recorrida con ella.

## Costes de una acción

Una misma acción puede requerir también otros recursos. Para realizarla debes cumplir todos sus costes y requisitos: gastar la acción indicada no sustituye el pago de [[Capacidad]], [[Energía]] u otros recursos que exija su descripción.

Consulta [[Acciones de Combate]] para conocer las acciones disponibles y sus costes.
