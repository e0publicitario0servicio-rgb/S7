Bienvenido a S7.

No es necesario aprender todo el sistema antes de comenzar a jugar. S7 está diseñado para aprenderse por etapas. Puedes empezar con las reglas fundamentales e ir incorporando nuevos módulos a medida que los necesites.

Si es tu primera vez, sigue este recorrido:

1. Comprende los conceptos básicos del sistema.
    
2. Crea un personaje.
    
3. Aprende cómo funcionan las tiradas.
    
4. Familiarízate con el combate.
    
5. Explora los módulos adicionales que quieras utilizar en tu campaña.
    

No es obligatorio utilizar todas las reglas. Cada mesa puede decidir qué módulos incorporar y cuáles dejar de lado. El sistema continuará funcionando de forma coherente.

## ¿Qué necesitas para jugar?

- Un personaje.
    
- Dados (d4, d6, d8, d10, d20) o un lanzador de dados digital.
    
- Un GM (también llamado Director).
    
- Este reglamento.
    

## ¿Qué encontrarás en esta documentación?

- **Reglas:** Las mecánicas fundamentales del sistema.
    
- **Creación de personajes:** Todo lo necesario para construir un personaje desde cero.
    
- **Equipo:** Armas, armaduras, objetos y recursos.
    
- **Director:** Herramientas y reglas orientadas a dirigir partidas.
    
- **Glosario:** Definiciones rápidas de términos utilizados en todo el reglamento.
    

No intentes memorizar todas las reglas. Siempre podrás volver a consultar cualquier apartado mediante el buscador, los enlaces internos o el glosario.

Cuando estés listo, continúa con **Conceptos básicos**, donde se presentan las mecánicas que sirven de base para todo el sistema.
