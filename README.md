# S7

Reglamento digital del sistema de rol S7.

Visita la web: [s7web.online](https://s7web.online)

## Desarrollo

El contenido se escribe en Markdown dentro de `content/`. Quartz genera el sitio estático y Cloudflare Pages lo publica automáticamente al enviar cambios a GitHub.

Este proyecto utiliza [Quartz](https://quartz.jzhao.xyz/) como motor de sitio estático. Su licencia MIT se conserva en [LICENSE.txt](LICENSE.txt).
